# LocalLead ZA

A mobile-friendly local discovery directory, starting with photographers and creative service providers in Kempton Park and the East Rand.

## Current MVP

- Responsive landing page
- Directory search and service filter
- Empty state while the first businesses are being recruited
- Free founding-listing application form
- Copyable application text (no details are transmitted by the static form)
- No paid services, backend, tracking, or third-party database

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `app.js` — directory filtering and application form interaction

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. GitHub will provide the published website URL after deployment.

## Before public launch

- Set up an official business email or WhatsApp Business contact channel.
- Create a secure form endpoint or connect a form service; the current application form only prepares copyable text and does not send submissions.
- Collect written permission before publishing any business name, photos, phone number, email, social link, or other listing information.
- Verify each business and its contact details with the owner.
- Add a privacy notice and a process for correcting or removing listings.
- Do not add paid listings until the free directory has demonstrated genuine customer demand.

## Zero-budget approach

Keep the site static and use free hosting. Do not buy a domain, paid ads, or subscriptions until the directory has real users and a clear reason to spend.
